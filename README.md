# Home Lab

3-node Proxmox VE cluster running enterprise-grade infrastructure for learning and certification preparation.

## Hardware
- 3x Lenovo Neo50q Gen4 (Intel i5)
- pve02: 16GB RAM — Infrastructure node
- pve03: 32GB RAM — Lab & Learning node
- pve04: 32GB RAM — Security & Monitoring node

## Scripts
- `scripts/update-all-nodes.sh` — updates all Proxmox nodes via SSH in one command
